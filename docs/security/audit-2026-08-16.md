## SAST detail (whole repo)

All 49 OWASP controls pass across `src/`, **128 edge functions**, **683
migrations**, `scripts/`, `docs/`, and `.github/workflows/`. Notable clean results:

- **XSS/DOM:** 21 `dangerouslySetInnerHTML` usages, all sanitized; 0 unguarded DOM
  sinks; DOMPurify clobbering + CSS-injection guards present.
- **Edge functions:** all 128 verify JWT (via `config.toml`) or carry a justified
  `@public-route`; all use the bounded JSON parser (no `req.json()` bypass).
- **Database:** every migration creating a public table enables RLS (683 audited);
  no raw-SQL execution paths.
- **AuthZ/IDOR, SSRF, secrets, crypto, prototype pollution, mass assignment,
  session, redirect/TLS, payment, WebSocket/XXE, LLM/MCP, privacy/zero-trust:** all
  guards present.
- **CI/CD supply chain:** all GitHub Actions SHA-pinned + least-privilege + no
  untrusted-context interpolation.

## Open item (accepted — no upstream fix)

**`quill` / `react-quill-new`** — XSS via Quill's HTML **export** feature
(GHSA-v3m3-f69x-jf25, low). Quill's latest release (2.0.3) is still the vulnerable
version, so there is nothing to upgrade to. All rendered HTML is sanitized through
the central DOMPurify sanitizer (`src/lib/security.ts`, enforced by
`SAST-NO-DANGEROUS-DOM-SINKS`), closing the exploit path. Full rationale and the
complete remediation history are in
[`dependency-advisories.md`](dependency-advisories.md).

## How this stays true

- **Every PR/push:** the required `ci / gate` runs the SAST sweep + coverage gate
  (`security-owasp` job) over the whole tree — see
  [ADR-0008](../adr/0008-owasp-secure-coding-ci-gate.md).
- **Nightly + on-demand:** `.github/workflows/security-audit.yml` re-runs this full
  audit and uploads a consolidated report, so drift is caught even with no commits.
