# Control Matrix — SPF Data Layer + Hand-Off System

The single most useful audit artifact: control → requirement → implementation → where the
evidence lives. Reuses already-audited platform controls (SSO, secrets, deploy records,
logging) where possible. Rows marked _(planned)_ land in the phase noted.

| Control                          | Requirement (skill)            | Implementation                                                                                                                                                                 | Evidence                                                              |
| -------------------------------- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------- |
| Access control / least privilege | SOC2 CC6; OWASP access-control | RLS: `active_participant` on own project to produce; any active member uploads; `has_role` admin; deny-by-default                                                              | RLS policies in migration; `@security` IDOR scenarios _(Phase B1)_    |
| Signed-URL scoping               | OWASP access-control           | short-lived, project-scoped, ownership re-checked                                                                                                                              | `createSignedUrl` call site; `@security` scenario _(Phase B3)_        |
| Encryption in transit + at rest  | SOC2 CC6.7; privacy            | TLS to SPF + the LLM provider (OpenRouter, cert-validate); Supabase at-rest for DB + private buckets                                                                           | infra config; ADR-0002                                                |
| Change management                | SOC2 CC8; release-safety       | expand/contract migrations; deployment record (SHA, flags, migrations); ADRs                                                                                                   | git history; `docs/adr/`; deploy log _(Phase A)_                      |
| Audit logging (tamper-evident)   | compliance audit-logging       | append-only log of produce/download/regenerate, SPF sync/replace, cross-project access, DSAR, retention jobs — ids not contents                                                | audit table + `@compliance` scenarios _(Phase A2/B3)_                 |
